Практична робота 8
Тема: Ознайомлення з мовою програмування PHP

Як запускати:
1. Скопіюйте папку Практична_робота_8_вебтехнології у C:\xampp\htdocs.
2. Запустіть Apache у XAMPP Control Panel.
3. Відкривайте файли через браузер за адресою:
   http://localhost/Практична_робота_8_вебтехнології/назва_файлу.php

Важливо:
PHP-файли не виконуються через file://. Їх потрібно запускати через localhost.
